AI application · Hybrid RAG

NCKU Academic
FAQ Assistant

I curated 137 FAQ entries from five NCKU academic-service offices into a searchable knowledge base. The system combines BM25 keyword retrieval and BGE-M3 semantic retrieval, then uses a local Ollama model to generate an answer accompanied by FAQ references.

Core capabilities

Find supporting FAQ entries before generating an answer.

Curated knowledge137 FAQ records from the Flexible Learning Office, Registration Division, Curriculum Division, Physical Education Office and General Academic Affairs Division.
Hybrid RetrievalBM25 finds keyword matches; BGE-M3 provides semantic retrieval.
Local modelOllama runs Llama 3.2 by default to generate answers using retrieved FAQ context.
ReferencesFAQ source references accompany the answer, separating source evidence from generated text.

Engineering details

API backendJava 21, Spring Boot 3 and LangChain4j connect the retrieval, model, and response layers.
Retrieval fallbackWhen embeddings are unavailable, the system falls back to BM25 and reports the actual retrieval method.
Evidence-aware abstentionUnknown categories, no relevant evidence or unresolved policy conflicts do not receive fabricated definitive answers.
Review toolingData audits and 100-question human-review scripts support evaluation; dataset size is not an accuracy score.

Architecture illustration
