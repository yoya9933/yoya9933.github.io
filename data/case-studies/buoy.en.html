Buoy observations · forecasts and charts

Buoy Analytics &
Navigation Risk Platform

I built a Streamlit site for working with buoy observations. It can fill missing values, plot the data, run LSTM forecasts and flag wave or wind conditions against set thresholds. Results can also be downloaded.

Features in the app

5forecast time scales: hour / day / week / month / year
4missing-value strategies
4exports: CSV / HTML / TXT / ZIP
3cached artifacts per model configuration

These numbers describe available features, not model accuracy. I don't have a fixed-dataset benchmark to report here.

Reading the forecast

Wave alertsThe significant wave height thresholds are set to 2.5 for warning and 4.0 for danger.
Wind alertsWind speed uses 10.0 for warning and 17.0 for danger.
Checking the modelTraining and validation data are split by time. The app shows RMSE, correlation R and epsilon hit rate.
Skipping repeat trainingThe app can reuse a saved model, scaler and training history when the settings match.
