線上象棋 · 多人對戰

楚河棋局
線上中國象棋

我做了一個可以和朋友連線下象棋的網站。除了標準象棋，還有揭棋、悔棋、棋譜回放和自訂棋局。朋友拿到房號後，就能在自己的裝置加入。

01 / 可以怎麼玩

房間和玩法目前有這些設定。

6碼房間代碼，分享即可加入
2主要棋類規則：標準象棋 / 揭棋
2主要 API：rooms / change-side
2資料庫後端：Neon Postgres / Cloudflare D1

另外也做了 AI 對手、雙方同意才能悔棋、棋譜回放和沙盤模式。程式會記錄玩家連線狀態，也會清除閒置超過 7 天的房間。

02 / 棋局怎麼同步

兩個人用不同裝置下棋，畫面就要跟得上每一步。

Browser UIHTML / CSS / JavaScript、棋盤與規則
HTTP APIGET / POST rooms、change-side
Revision Syncpolling、player token、heartbeat
PersistenceNeon Postgres 或 Cloudflare D1

03 / 遇到的幾個問題

棋步同步用 polling 和 revision 記錄棋局版本，避免較慢的裝置把新棋步覆蓋掉。
斷線回來在瀏覽器保存玩家 token，重新連線時可以回到原本的位置。
不同玩法同一個棋盤支援標準象棋、揭棋、沙盤和自訂局面。
保存棋局資料庫會記錄局面、版本、玩家連線狀態和悔棋請求。
