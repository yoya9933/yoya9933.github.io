線上象棋 · 多人對戰

楚河棋局
線上中國象棋

我做了一個可以和朋友連線下象棋的網站。除了標準象棋，還有揭棋、悔棋、棋譜回放和自訂棋局。朋友拿到房號後，就能在自己的裝置加入。

已完成的產品與驗證

這是一個已上線的多人象棋網站，不只是一個棋盤畫面。

可以實際連線對局支援標準象棋與揭棋，玩家能用房號加入、重連及回放棋譜。
伺服器處理棋局Worker 驗證棋步，D1 保存狀態，Durable Object 與 WebSocket 通知雙方更新。
公開自動化驗證CI 執行單元測試、多人 E2E 和瀏覽器 smoke test，相關程式與流程都能查看。
尚無正式效能數字沒有公開的同時在線人數、同步延遲分布或壓力測試結果，不把測試類型數量當作效能。

棋局怎麼同步

兩個人用不同裝置下棋，畫面就要跟得上每一步。

Browser UIHTML / CSS / JavaScript、棋盤與規則
Worker 規則判定驗證棋步與局面狀態
Durable Object + WebSocket即時通知，polling 作為備援
Cloudflare D1權威棋局、歷史與版本資料

遇到的幾個問題

棋步同步用 WebSocket 通知雙方更新，斷線時有 polling 備援；棋局 revision 避免舊版本覆蓋新棋步。
斷線回來在瀏覽器保存玩家 token，重新連線時可以回到原本的位置。
不同玩法同一個棋盤支援標準象棋、揭棋、沙盤和自訂局面。
保存棋局資料庫會記錄局面、版本、玩家連線狀態和悔棋請求。

遊戲畫面

楚河棋局 · 目前版本

這是目前網站的遊戲畫面。

棋盤、房間和操作介面都在這個網站裡。除了玩法，我也花時間處理兩人連線時的狀態問題。

目前已把棋步合法性檢查放在伺服器端，並加入單元與端對端測試；正式網站的延遲或大規模同時在線人數，尚沒有公開的量測結果。

測試與可查證的部分

同步、棋規和重連都有自動化驗證。

專案的 CI 依序執行 npm test、多人對局 E2E 和瀏覽器 smoke test；測試包含伺服器棋規、權限、WebSocket、棋鐘及重連等情況。這是功能與回歸測試，不等於已量測正式環境的延遲或容量。
