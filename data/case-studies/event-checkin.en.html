NCKU-hosted TCUS faculty camp

Event Check-in &
Operations System

NCKU hosted the 2026 TCUS New Faculty Professional Development Camp, and I worked on the backend for its check-in system. On the day, staff could scan QR codes, find attendees, check seat assignments and see the latest check-in counts.

Production use: August 28, 2026, at National Cheng Kung University International Conference Hall. official event page ↗. The production repository and database remain private; the public demo uses synthetic data and exposes no persistent write access.

Export a listStaff can download their filtered results as UTF-8 CSV for handoff or later review.

04 / Keeping real data private

The demo lets people try the interface without accessing the real attendee list.

  • The production repository is private. Attendee names, QR tokens, seat details and admin passwords aren't published.
  • The demo uses made-up branding and people instead of the real event's identifiers.
  • The public admin view is read-only. Simulated scans only change browser memory and reset when the page reloads.
  • The portfolio isn't connected to the production database and cannot write to the real admin system.
