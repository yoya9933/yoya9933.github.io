現場能用的功能

現場人數能看到總人數、已報到、已入席、現場報名和最新一筆報到。
快速找人可以用姓名、ID、學校、系所和報到狀態篩選名單。
臨時調整正式後台能新增現場報名的人、修改座位或更新入席狀態。
匯出名單把篩選後的資料存成 UTF-8 CSV，方便現場交接或事後整理。

正式資料沒有公開

公開版只讓大家了解功能，不會碰到正式名單。

  • 正式程式庫不公開，也不會在作品集放參加者姓名、QR token、座位或管理密碼。
  • Demo 裡的活動名稱、人物和聯絡資料都換成虛構內容。
  • 公開後台只提供展示；掃描模擬的變化只留在瀏覽器裡，重整就會恢復。
  • 作品集沒有連到正式資料庫，也沒有提供可修改正式資料的 API。

我負責的部分

這次我主要負責後端與資料處理。

最重要的是讓報到狀態、名單查詢、座位與現場調整都能透過 API 正確寫入和讀取。這些功能已經在實際研習營中用過。

現場要處理的問題

同一份名單要跟得上報到、臨時報名和座位異動。

活動現場不只有掃 QR Code：現場新增的人也需要進入名單，座位和入席狀態也會變動。我負責讓 API 與資料庫支援這些讀寫流程，讓工作人員能在同一套系統裡查詢與彙整。

能公開驗證的是活動使用背景、功能範圍與隱私安全 Demo；正式活動實際處理人次、尖峰每秒請求數和平均報到秒數並未公開，因此沒有當作實測績效。
