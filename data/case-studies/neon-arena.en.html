Multiplayer Hold'em · friends-only game

Neon Arena
Real-time Multiplayer Hold'em

I made an online Hold'em table for 2–6 friends. The server handles cards, turn timers, reconnects and main/side pot settlement. Chips are only used in the game—there's no payment, deposit or cash-out.

How the game works

Friends join with a six-digit room code, and the server keeps track of the hand.

2–6players per table
18sturn deadline
6digit room codes
1Durable Object per room

If someone joins halfway through a hand, they watch until the next one. Players can reconnect without losing their chips, and the host role passes to someone still online if needed.

How the table stays in sync

Players choose an action, but the server checks whether it's allowed.

Browser ClientReact UI, room join, action confirmation, reconnect
Worker APIsame-origin API, input limits, room routing
Durable ObjectWebSocket, identity, turn state, alarms
SQLiteroom persistence, chips and game state

Things that needed extra care

Keep hole cards privateEach player only gets their own cards until the showdown, when the remaining players' hands are revealed.
Don't trust the browser with resultsDealing, valid actions, chip amounts, turns and payouts are handled on the server.
Reconnects and duplicate tabsA returning browser can take back its seat. If two tabs are open, the newer one takes over the connection.
Main and side potsMultiple all-in bets can create side pots. The game evaluates the hands and distributes chips and refunds separately.
