Overtime
Operations System

This system is currently used by NCKU's Center for Teaching and Learning Development. Staff can submit overtime requests, managers can review them, and administrators can look up and organize the records in one place.

Used by: NCKU Center for Teaching and Learning Development. Official unit website ↗. Production accounts and staff data aren't public. This is a description of an internal tool I built, not the university's official campus-wide overtime system. Formal approval and reimbursement still follow university procedures.

How people use it

Staff submit requests, managers review them, and administrators organize the results.

Employeedate, time, reason and requested hours
Managerpending queue, approve or reject
Secretary / Adminconsolidation, users and role controls
D1requests, users, sessions and approval logs

Checks before submission

Checking the timeThe backend checks start times, 30-minute intervals and durations again after submission.
Preventing duplicatesIf another request for the same day hasn't been rejected, the system checks for overlapping hours.
Different permissionsEmployees, managers, secretaries and admins see different controls. Sensitive actions are checked again on the server.
Sign-in securityThe system uses first-login password changes, PBKDF2-SHA256 hashing, hashed session tokens and HttpOnly cookies.
