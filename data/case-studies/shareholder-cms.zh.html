股東紀念品服務與
內容管理平台

這是幫「大倉代領」做的服務網站。訪客可以查詢商品、服務內容和公告；管理者登入後，就能直接更新商品、圖片和公告，不必每次都找人改程式。

這裡只介紹能從程式碼確認的功能。商家的聯絡資料與正式後台畫面沒有放上來，也不引用尚未驗證的效能數字。

03 / 訪客看到的部分

手機也能瀏覽網站用 Vue 3、TypeScript、Vite 和 Tailwind 製作，手機、平板與電腦都能使用。
服務與商品訪客可以看服務方案、商品照片、公告、聯絡方式與招募資訊。
搜尋引擎資訊有設定頁面資訊、sitemap、robots.txt 和 JSON-LD，方便搜尋引擎理解網站。
圖片顯示README 有記錄響應式圖片，以及 AVIF、WebP、JPEG 的相容處理方式。

04 / 管理者怎麼更新

商品上架或公告更新，都可以在登入後操作。

  • 管理者用 Supabase 的電子郵件和密碼登入。
  • 可以新增、修改、刪除公告，並設定類型與標籤。
  • 可以編輯商品、價格、分類，以及上架或下架。
  • 圖片放在 Supabase Storage，商品與公告資料保存在 PostgreSQL。
  • 資料庫用 Row Level Security 管理資料存取權限。

05 / 使用的工具

Vue 和 TypeScript將頁面、共用邏輯與資料型別拆開，方便修改不同功能。
Supabase登入、資料庫和圖片儲存都交給 Supabase，不用另外架三套服務。
內容後台日常改公告、換商品不需要直接編輯程式碼。
GitHub Actions用 Git 管理修改紀錄，再透過 Actions 部署網站。

06 / 做完這個網站之後

網站上線後，商品和公告還是會持續變動。

所以我把管理後台和公開頁面一起做進去。網站不只是給訪客看的頁面，管理者也能自己維護日常內容。
