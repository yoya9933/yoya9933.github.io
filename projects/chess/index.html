CASE STUDY / WEB PRODUCT

楚河棋局｜線上中國象棋

免註冊、用房間代碼即可跨裝置對弈；除了棋盤本身，也處理玩家身分、房間同步、悔棋、棋譜、AI 與資料庫狀態。

JavaScriptNext.js / VinextNeon PostgresREST APIState Sync
開啟 Demo查看 GitHub

產品問題

不用登入也要認得玩家

以瀏覽器 localStorage 保存玩家 token，讓使用者重新整理或重新加入房間時可以回到原席位。

兩台裝置不能互相覆蓋

房間狀態帶 revision，更新時檢查版本，降低 polling 架構下的競爭覆寫。

架構

Browser UI→/api/rooms→Revision Control→Neon Postgres / D1

核心功能

多人房間

6 碼房間代碼、紅黑方選擇、換邊、heartbeat 與斷線後重新同步。

棋局工具

標準象棋、揭棋、悔棋、棋譜回放、沙盤推演、自訂棋局與單機 AI。

資料層

房間 state 以 JSON 保存，並記錄 revision、玩家 token、heartbeat、悔棋狀態與更新時間。

已知限制

目前主要同步仍採 HTTP polling，且 Server 尚未完整重新驗證所有象棋合法走法；這也成為下一步架構改善重點。

下一步

抽出共用 game engine、讓 Server 成為規則權威來源，再補自動測試與更即時的同步方式。
