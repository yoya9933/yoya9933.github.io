CASE STUDY · WEB PRODUCT

楚河棋局
線上中國象棋

把象棋規則、跨裝置房間、狀態同步、資料庫與多種玩法整合成可以直接使用的 Web 產品。

Live Demo ↗GitHub ↗

01 / Product

不用註冊，也能跨裝置開房對弈。

使用房間代碼加入棋局，並支援標準象棋、揭棋、AI、悔棋、棋譜回放、沙盤推演與自訂棋局。

02 / Architecture

前端互動與房間狀態分開處理

Browser UI→Rooms API→Revision Control→Neon Postgres

03 / Challenges

多人同步使用 polling 與 revision 機制避免舊狀態覆蓋新狀態。
Room Identity使用房間代碼與玩家 token 區分對局與玩家。
Rule Variants同一棋盤支援標準象棋、揭棋、沙盤與自訂棋局。
Persistence房間與對局狀態落到資料庫，而不是只存在單一瀏覽器記憶體。

04 / Result

從小遊戲變成完整產品結構。

這個專案證明我能處理互動 UI、API、資料庫與部署，而不是只製作靜態前端。
