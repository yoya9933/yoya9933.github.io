CASE STUDY · DECISION TOOL

NCKU Return OS
學分地圖

把畢業學分、必修缺口、先修限制、衝堂與 GPA 風險整理成一個能持續更新的修課決策工具。

Live Demo ↗GitHub ↗

01 / Problem

修課不是只有「還差幾學分」。

真正的決策還牽涉必修、先修、開課學期、衝堂、GPA 風險與復學後可承受負荷，因此需要一個可更新的規則型工具，而不是一次性的試算表。

02 / Decision Flow

把零散條件變成決策流程

Completed Credits→Requirement Gap→Course Offering→Prerequisite / Conflict→Risk Score→A / B / C Plan

03 / Features

Gap Analysis追蹤總學分、必修、通識與選修缺口。
Course Decision用必要性與風險分數整理候選課程。
Conflict Matrix把下學期可能選到的衝堂組合集中比較。
Portable DataLocalStorage 保存狀態，並支援 JSON 備份與 CSV 匯出。

04 / Product Thinking

先解決自己的真實問題，再把流程產品化。

這個專案的重點不是複雜框架，而是把規則、資料與操作流程整理成低成本、容易維護、能持續使用的 Decision Support Tool。
