NCKU Return OS｜學分地圖

把畢業規則、抵免紀錄、課程缺口、先修限制、衝堂與 GPA 風險整理成可操作的決策工具，讓復學排課不再只靠試算表與記憶。

問題

畢業規則不是單一數字

除了總學分，還包含核心／專業必修、設計必修、必選修、本系選修、體育與英文門檻等多層條件。

排課是風險決策

是否該修一門課不只看有沒有開，還牽涉先修、衝堂、GPA 風險、延後風險與畢業卡關程度。

決策流程

已完成學分→規則缺口→115-1 開課→先修 / 衝堂→風險評分→A / B / C 方案

核心實作

學分缺口分析

計算已完成、尚缺學分與分類進度，並額外檢查設計必修與水利及海洋工程概論等規則。

課程決策器

以 necessityScore、riskScore、decisionStatus 推導四象限與建議等級，並支援 A／B／C 修課方案。

本地資料保存

使用 LocalStorage 保留狀態，並提供 JSON 備份／還原與 CSV 匯出，避免工具被綁死在單一瀏覽器狀態。

可驗證規則

核心學分計算與篩選邏輯有 Node.js 測試入口，降低規則調整後產生回歸錯誤的風險。

我想證明的能力

從自己的真實需求出發，把複雜規則轉成資料結構、可解釋邏輯與可重複使用的決策介面。
